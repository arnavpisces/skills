# Contributing

Contributions are welcome through fork-based pull requests.

1. Fork [arnavpisces/skills](https://github.com/arnavpisces/skills).
2. Create a branch in your fork for your change.
3. Add or update the skill and its relevant supporting files under `skills/<skill-name>/`.
4. Update the root README with the skill's description, usage, requirements, and repository layout where relevant.
5. Validate changed instructions, relative links, and any helper scripts. Keep credentials, device diagnostics, generated output, and local machine state out of commits.
6. Open a pull request from your fork's branch into `arnavpisces/skills:main`. Explain what changed and how you checked it.

The repository's `main` branch restricts updates to `@arnavpisces`. The owner can push directly and merges accepted pull requests. Contributors do not need write access to this repository; submit changes from your own fork.
